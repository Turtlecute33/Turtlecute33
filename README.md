## 🐢 Turtlecute

A cute turtle that doesn't know how to code. 1,000+ contributions later, still true.

Privacy and Bitcoin, from Italy. I write the guides ([turtlecute.org](https://turtlecute.org)), then I build the apps the guides were missing. I also host [Il Priorato del Bitcoin](https://priorato.org), a podcast in Italian.

**Slow, but it ships**

| Project | What it does |
|---|---|
| [adblocktest](https://adblock.turtlecute.org) | Tells you if your ad blocker works. About 85,000 people a month want to know. |
| [PrivacyActivistKit](https://privacyactivistkit.org) | Digital self-defense for activists and journalists |
| [privacy.sexy Revamped](https://privacy.turtlecute.org) | Debloat and harden Windows, macOS, Linux |
| [Fonte](https://github.com/Turtlecute33/Fonte) | Android app updater that still works when GrapheneOS blocks dynamic code loading |
| [WisprBoard](https://github.com/Turtlecute33/WisprBoard) | A keyboard that types what you say. Your key, no account |
| [btcpayapp](https://github.com/Turtlecute33/btcpayapp) | BTCPay Server on Android, no WebView |

Yes, a lot of these are forks. Good tools deserve a maintainer.

When the threat model allows, I go fishing. I built a site to pick the spot: [dovepescare.com](https://dovepescare.com).
